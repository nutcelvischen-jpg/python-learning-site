# 開始之前

歡迎來到 **Python 學堂**！ 在開始寫第一行程式碼之前，赫哥想先跟你聊聊這門課的設計理念。

## 🎯 這門課的目標

**最終目標：讓你能自己用 Python 分析真實世界的資料。**

不是「教你所有 Python 語法」，而是「教你 80% 日常會用到的 Python，並且讓你能做有意義的事」。

具體來說，上完這門課你會能：

- ✅ 讀懂別人寫的 Python 程式碼
- ✅ 自己寫 50-200 行的實用小工具
- ✅ 用 pandas 整理、清洗、分析資料
- ✅ 用 matplotlib / seaborn 畫出發表品質的圖表
- ✅ 看懂基本統計概念（p-value、信賴區間、相關分析）
- ✅ 對機器學習、爬蟲、部署有正確的認識，知道下一步往哪走

## 📐 每堂課的固定結構

每個小節都遵循相同結構，幫助你系統性學習：

```text
1. 學習目標        ← 3-5 個 bullet，讀者先知道會學到什麼
2. 前置知識        ← 標示依賴哪些章節
3. 概念講解        ← 白話文 + 類比 + 圖解
4. 程式碼範例      ← 3-5 個可執行的 code cell，含繁中註解
5. 常見錯誤        ← 該小節 Top 5 errors + 修正
6. 練習題          ← 5 題（由易到難）
7. 小結            ← 1 段話 recap
8. 延伸閱讀        ← 3-5 個官方文件 / 優質教學連結
```

每章節末尾有：
- **小專案** — 30-60 min 整合該章所有概念
- **章末測驗** — 選擇題 + 實作題

## 💡 給學習者的 5 個建議

!!! tip "建議 1：不要只想著『讀完』"

    程式設計是**做出來**的技能，不是**讀完**的知識。 每學一個概念，**立刻動手寫**。 就算只是把範例重新打一次也有效。

!!! tip "建議 2：犯錯是正常的"

    每個 Python 工程師每天都在 `print()` 變數 debug。 第 0.5 章會教你看懂錯誤訊息、怎麼問問題。

!!! tip "建議 3：跳過你不理解的，先繼續往前"

    第一次看不懂的概念，先標記起來，繼續讀下去。 很多時候，後面的章節會回頭解釋前面的東西。

!!! tip "建議 4：練習題一定要寫"

    練習題是「把讀過的東西變成你的能力」的橋樑。 答案在[附錄 E](appendix/E-answers.md)，但**先自己寫再看答案**。

!!! tip "建議 5：找個小專案邊做邊學"

    學到第 5 章時，試著用真實資料做點小東西（你最愛的球隊、你的記帳、你家的電費）。 動手做比讀十本書有效。

## 🌍 為什麼這本書用台灣資料？

赫哥是台灣人，這門課的主要讀者也是台灣學習者。 所以：

- 範例用 **環保署空品資料**、**實價登錄**、**Threads** 等台灣在地資料
- 程式碼註解、變數命名用**繁體中文**
- 統計章節特別強調**台灣常見的統計誤用**（如選舉民調的解讀）
- 第 8.5 章「空汙 × 房價」是**環境經濟學領域的完整研究案例**
